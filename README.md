# 小屋日常

## 怎么玩

- 拖动旋转视角，右键或双指平移，滚轮或双指缩放
- 点"跟小豆"或"跟橘子"，镜头会一直跟着他们
- 默认是真实时间；点"加速"可以快进，从 ×60 到 ×1440，×1440 时一分钟过完一整天；加速时按空格暂停

<details>
<summary><b>小豆会做的每一件事</b></summary>

箭头表示分几步、依次走到哪件家具。

- **睡觉**：洗手台刷牙洗脸 → 衣柜换睡衣 → 拉上窗帘 → 上床睡一整夜，头顶飘 Zzz
- **午睡**：直接上床躺一小时左右，不换衣服不拉窗帘
- **起床**：睡醒后拉开窗帘，顺便上厕所
- **换家居服**：起床后去衣柜把睡衣换掉
- **刷牙洗脸**：洗手台，手里拿牙刷，水龙头滴水
- **上厕所**：马桶坐着玩手机 → 洗手台洗手
- **喝水**：水槽接水，手里拿杯子喝
- **早餐**：冰箱拿鸡蛋 → 灶台拿锅铲煎蛋，灶上冒热气 → 坐吧台凳吃
- **正餐**：冰箱拿食材 → 砧板拿刀切菜 → 灶台炒菜 → 餐桌坐下吃 → 把盘子放回水槽。比早餐多了切菜，在餐桌吃，会留下脏碗
- **零食**：翻冰箱 → 坐吧台吃，不做饭
- **咖啡**：咖啡机做 → 吧台喝，杯子冒热气
- **泡茶**：咖啡机泡 → 端到阳台椅上坐着喝
- **冲澡**：站在淋浴间，有水流和雾气，出来头上裹毛巾
- **泡澡**：先在浴缸边放水，水位慢慢涨 → 跨进去躺着，冒泡泡
- **护肤**：坐梳妆台前
- **洗碗**：有洗碗机就蹲着往里装，否则在水槽手洗，水槽里堆的脏碗消失
- **洗衣服**：卫生间脏衣篓蹲下收衣服 → 抱到洗衣机放进去，滚筒开始转
- **晾衣服**：洗衣机取出 → 抱到阳台晾衣架挂上
- **收衣服**：阳台收下 → 抱回衣柜叠好
- **买菜**：换鞋凳换运动鞋 → 衣帽架穿外套 → 垃圾满了就带上垃圾袋 → 照镜子 → 出门消失 → 回来挂外套 → 换拖鞋 → 把菜放进冰箱
- **扔垃圾**：垃圾桶打包 → 拎着袋子出门，几分钟就回来。不换鞋不穿外套
- **浇花**：水槽接水拿水壶 → 挨个走到缺水的花前浇，蔫的花会挺起来
- **喂猫**：拿猫粮袋 → 蹲在猫碗前倒，碗里出现猫粮
- **铲猫砂**：拿铲子蹲在猫砂盆前
- **撸猫**：走到猫在的地方，猫在地上就蹲下摸，在沙发或床上就站着弯腰摸，猫冒爱心
- **逗猫**：猫爬架拿逗猫棒 → 健身角空地挥，猫过来扑 → 放回逗猫棒
- **看电视**：坐沙发，电视亮，画面颜色慢慢变
- **打游戏**：同一个沙发位，手里拿手柄，游戏机亮，电视颜色闪得快
- **听唱片**：唱片机放唱片，唱片转起来飘音符 → 坐沙发另一头听
- **弹吉他**：吉他架拿吉他 → 坐沙发抱着弹，飘音符 → 放回
- **看书**：书架挑一本 → 坐阅读椅看
- **办公**：书桌，显示器亮，打字
- **玩电脑**：和办公一样的位置和动作，算娱乐不算工作，画面上看不出区别
- **跑步机**：站上去跑，履带转
- **瑜伽**：在瑜伽垫上做动作
- **哑铃**：从架子拿哑铃举，再放回
- **看风景**：阳台栏杆边站着
- **发呆**：随便走到一个地方站着，伸懒腰挠头

</details>

<details>
<summary><b>橘子会做的每一件事</b></summary>

- **睡觉**：蜷着睡，地点很多：猫窝、沙发两端、懒人沙发、猫爬架顶、床上、阅读椅、阳台
- **床尾陪睡**：夜里小豆睡着了才有，专门睡床尾
- **吃猫粮、喝水**：两个碗，动作一样
- **讨饭**：碗空了就蹲在碗边叫
- **上猫砂**：跳进猫砂盆
- **舔毛**：就地坐下舔
- **巡视**：随便走到一处站着张望
- **看窗外**：坐在阳台门口朝外看
- **磨爪子**：在猫爬架底部
- **趴猫爬架顶**：分两段跳上去趴着
- **晒太阳**：阳台地上趴着
- **跟着小豆**：走到小豆旁边坐下盯着他，他换地方就跟过去
- **挨着小豆**：小豆坐沙发时跳上去贴着趴
- **跑酷**：突然连跑三个地方
- **门口等人**：小豆出门久了就去门口蹲着
- **蹭腿**：小豆回家时跑到门口蹭腿，冒爱心
- **盯机器人**：跟在扫地机器人后面蹲着看，它走远了就追

</details>

<details>
<summary><b>屋子里自己会动、会变的东西</b></summary>

- **扫地机器人**：每天上午十点出发，一个房间一个房间扫：洗衣角、厨房、餐厅、玄关、健身角、过道、卫生间、卧室、工作区、客厅。每个房间先沿墙边和家具边走一圈，再一趟挨一趟来回走直线，刷子转、带起灰尘，灯是蓝的。全屋扫完大约两个小时，回座充电，灯是橙的，充满变绿。小豆睡觉时不出来；扫到一半他去睡了或者没电了，就先回座，之后从没扫完的房间接着扫。加速模式下它看起来像延时摄影，跑得飞快
- **天色**：天空、阳光颜色和窗户里的颜色跟着时间变，清晨和傍晚偏橙，夜里深蓝
- **自动开灯**：天黑且小豆醒着在家时，台灯灯罩亮起，屋里变暖变亮；他睡了或出门了就关
- **挂钟和闹钟**：客厅挂钟的指针跟着时间走，床头闹钟夜里和早上 7 点前亮红色
- **盆栽**：7 盆花会慢慢缺水，缺得厉害时叶子耷拉发黄，要等小豆来浇
- **脏衣篓**：每天慢慢变满，看得到衣服堆高，满了小豆才会去洗
- **洗衣机**：放进衣服后滚筒自己转一个小时，转完等小豆来取
- **晾衣架**：衣服挂上后要晒四个小时才干
- **洗碗机**：装好后自己洗一个半小时，亮绿灯
- **唱片机**：放上唱片后自己转将近一个小时，小豆走开了也继续放、继续飘音符
- **阳台推拉门**：小豆或橘子走近就自己滑开，走远了关上

小豆和橘子用过以后也会留下痕迹：水槽脏碗堆起来、冰箱吃空、垃圾桶变满、猫碗变空、猫砂变脏。

</details>
