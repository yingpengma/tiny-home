# 小屋日常 · Tiny Home

一个独居在 3D 开放式大平层里的小人"小豆"和他的橘猫"橘子"，各自按需求过日子。

**在线访问：** https://yingpengma.github.io/tiny-home/

## 小豆

- **需求驱动**：饱腹 / 水分 / 膀胱 / 精力 / 娱乐 / 清洁 6 项需求随时间下降，按"紧急程度 + 时段偏好 + 随机"挑下一件事
- **30 多种日常**：刷牙洗脸、做早餐、切菜炒菜、吃饭收碗、洗碗/装洗碗机、冲澡、泡澡、护肤、换睡衣/家居服、拉窗帘、
  工作日居家办公、看电视、打游戏、听唱片、弹吉他、看书、跑步机/瑜伽/哑铃、阳台喝茶看风景、
  洗衣服 → 阳台晾衣服 → 收衣服进衣柜、浇花、换鞋穿外套出门买菜/扔垃圾、喂猫、铲猫砂、撸猫、拿逗猫棒逗猫……
- **动作**：两节式四肢（膝盖/手肘），走路有起步加速和停步减速、转弯先转头；坐下/起身/上床/跨进浴缸都是分段动作；
  随机小动作（伸懒腰、挠头、打哈欠、摸肚子）；表情会随状态变化（开心、困、专注、饿、咀嚼）
- **换装**：家居服 / 睡衣 / 外套 / 运动鞋 / 洗完澡头上的毛巾

## 橘子

吃饭、讨饭（碗空了会守着碗叫）、喝水、上猫砂盆、舔毛、磨爪子、爬猫爬架、晒太阳、看窗外、巡视领地、突然跑酷、
跟着小豆、跳上沙发挨着小豆、晚上跑到床尾陪睡、在门口等小豆回家、追着扫地机器人看……

## 屋子

卧室、卫生间（马桶/淋浴/浴缸）、洗衣角、开放厨房 + 中岛、餐厅、客厅、工作区、健身角、玄关、阳台。
物件有状态：脏碗会堆在水槽、脏衣篮会慢慢变满、盆栽缺水会蔫、冰箱会吃空、垃圾桶会满、扫地机器人每天定时出来扫。
天色、阳光随时间变化，天黑且小豆醒着时自动开灯。

## 时间

默认和访客本地时间同步；可以切到加速模式（×60 ~ ×1440，空格暂停）。

## 本地运行

纯静态网页，three.js 已放在 `vendor/` 里，不需要 npm / 构建。ES Module 不能双击打开，需要起一个静态服务器：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

调试参数：`?time=21.5` 从 21:30 开始并进入加速模式，`?speed=8` 指定加速档位（每真实秒走多少游戏分钟）。

## 代码结构

| 文件 | 作用 |
|---|---|
| `src/house.js` | 房子、家具、灯、交互点、碰撞体、物件状态 |
| `src/activities.js` | 小豆所有行为的打分规则和执行步骤，**加新行为改这里** |
| `src/agent.js` | 小豆的需求、决策，以及走路/坐下/躺下等分段动作编排 |
| `src/character.js` | 小豆的模型、换装、表情和程序化动作 |
| `src/cat.js` | 橘子的模型和行为 |
| `src/robot.js` | 扫地机器人 |
| `src/motion.js` | 走路（加减速、转身）和分段过渡 |
| `src/grid.js` | 0.25m 网格 + A* 寻路 |
| `src/particles.js` | 热气、水滴、泡泡、音符、Zzz、爱心等粒子 |
| `src/contact.js` | 人、猫、机器人脚下的接触阴影（屋里没有太阳硬影子，靠它让东西不飘） |
| `src/bake.js` | 把一起运动的零件合成一个网格，减少 draw call |
| `src/lighting.js` | 昼夜光照 |
| `src/ui.js` / `src/main.js` | 界面、时钟、主循环 |
